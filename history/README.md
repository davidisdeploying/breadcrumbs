# breadcrumbs-history

Self-hosted price-history service for retailer-aware Breadcrumbs exports: Node + better-sqlite3 API + Vite/React dashboard. Legacy exports without a `retailer` field default to Kroger; current Kroger, H-E-B, and Amazon captures preserve retailer provenance.

## Usage
- `npm install`
- `npm run build`
- `npm start`
- `npm test`
